# Water Scarcity Analytics — Exploratory Data Analysis

## Project Overview

This notebook explores relationships among rainfall, groundwater, extraction/recharge, population, demand, supply, and a supplied scarcity indicator.

The goal is to practise cleaning, feature engineering, trend analysis, correlation analysis, and visualization while avoiding causal claims that the dataset cannot establish.

## Analytical Areas

- missing-value and outlier checks
- engineered water-deficit measures
- extraction/recharge ratios
- time-based patterns
- demand vs supply comparisons
- groundwater-related trends
- correlation and scatter analysis

## Engineered Features

- water deficit
- groundwater stress
- extraction/recharge ratio

## Interpretation Note

Observed correlations or trends should be treated as **dataset-level associations**. They do not prove that one variable causes another, and they should not be used alone for real-world policy decisions.
